Category

Import/Export

From Unofficial Stationeers Wiki

Description Stationpedia[edit]

These are structures, typically powered, that are able to receive and output other items, or assist this. Most have specialist functions including logic, atmospherics, and more. They are constructed in the same way as other structures.

Code of practice[edit]

All structures who can be connected with Chutes get the category "Import/Export". It doesn't matter if a structure only supports importing, only exporting or both.
