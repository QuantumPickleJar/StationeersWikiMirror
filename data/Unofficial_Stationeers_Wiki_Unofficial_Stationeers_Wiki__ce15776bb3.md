<languages /> [[Category:Machines]] {{Itembox | name = Kit (Fabricator) | image = [[File:Fabricator_kit.jpg]] | createdwith = [[Electronics Printer]], [[Fabricator]] | cost = 20g [[Copper]], 5g [[Gold]] }} {{Structurebox | name = Fabricator | image = [[File:Fabricator.jpg]] | placement = Small Grid | powerusage = 5W + Recipe Usage }} == Description == The [[Fabricator]] is an advanced machine used to manufacture most of the craftable items in the game. It largely fills the role of the [[Autolathe]], [[Electronics Printer]], [[Hydraulic Pipe Bender]] and [[Tool Manufactory]]. == Usage == In order to use the fabricator, you will need to set up a [[Computer]] with a [[Motherboard (Manufacturing)]] and connect it to the fabricator's data port. You can then use the manufacturing interface in order to request manufacturing jobs from the fabricator. You can choose the quantity of each item you want to build and set up a queue of items to be manufactured. If the fabricator is unable to finish an item, it will idle until it is able to continue (materials are added or power is resumed).
