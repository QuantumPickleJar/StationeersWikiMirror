<languages /> <div class="mw-translate-fuzzy"> {{Itembox | name = Kit (Fabricator) | image = [[File:Fabricator_kit.jpg]] | createdwith = [[Electronics Printer|Принтер электроники]], [[Fabricator|Фабрикатор]] | cost = 20g [[Copper|Медь]], 5g [[Gold|Золото]] }} </div> {{Structurebox | name = Фабрикатор | image = [[File:Fabricator.jpg]] | placement = Small Grid | powerusage = 5W + Recipe Usage }} == Описание == [[Fabricator|Фабрикатор]]- это машина для сборки большей части создаваемых предметов в игре. По большому счету он выполняет роль [[Autolathe]], [[Electronics Printer]], [[Hydraulic Pipe Bender|Гидравлический трубогиб]] и [[Tool Manufactory]] вместе взятых. == Использование == Для того, чтобы использовать фабрикатор, вам нужно поставить [[Computer|компьютер]] с [[Motherboard (Manufacturing)|материнской платой (производство)]] внутри и подсоединить его к порту данных фабрикатора. После этого вы сможете использовать производственный интерфейс для работы с фабрикатором. Вы можете выбрать кол-во предметов, которые хотите создать а также настроить очередность производства. Если фабрикатор не может закончить работу по какой-то причине, то он будет ждать, пока проблема не будет решена (например, пока не будут добавлены необходимые ресурсы или пока не восстановится энергоснабжение).
