## Import/Export

### From Unofficial Stationeers Wiki

##### 

## Description Stationpedia[[edit](/index.php?title=Category:Import/Export&action=edit&section=1 "Edit section: Description Stationpedia")]

These are structures, typically powered, that are able to receive and output other items, or assist this. Most have specialist functions including logic, atmospherics, and more. They are constructed in the same way as other structures. 

## Code of practice[[edit](/index.php?title=Category:Import/Export&action=edit&section=2 "Edit section: Code of practice")]

All structures who can be connected with [Chutes](/Chutes "Chutes") get the category "Import/Export". It doesn't matter if a structure only supports importing, only exporting or both.
