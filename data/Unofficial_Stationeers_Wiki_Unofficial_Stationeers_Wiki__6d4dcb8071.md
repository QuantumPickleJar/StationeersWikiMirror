== Description == <!--T:2--> Used to create pipes, filters, portable structures, and some general-purpose items. Takes ingots in the left and spits product out of the right. Power button toggles machine power state. Lever will eject materials inside if machine is powered. Arrow buttons select recipe, push the square button in between to craft. Magnifying glass button below the craft button opens a search interface for easier recipe selection. The Hydraulic Pipe Bender can be upgraded to a Tier Two version by using its respective [[Mod Kit]] and a [[Welder]] on it. '''Note: The machine will continue to craft until the button is pushed again, the entire machine is turned off, or in case it loses power.''' '''If you want to craft only a single item unattended, start the craft and press any of the arrow buttons.'''
