== Usage == <!--T:3--> In order to use the fabricator, you will need to set up a [[Computer]] with a [[Motherboard (Manufacturing)]] and connect it to the fabricator's data port. You can then use the manufacturing interface in order to request manufacturing jobs from the fabricator. You can choose the quantity of each item you want to build and set up a queue of items to be manufactured. If the fabricator is unable to finish an item, it will idle until it is able to continue (materials are added or power is resumed).
