## Item box with recipe variants --->[[edit](/index.php?title=User:Sunspots/sandbox&action=edit&section=1 "Edit section: Item box with recipe variants --->")]

  
Recipes differ from machine to machine (in all components - reagents, time and energy), but there are efforts to bring all reagent costs the same for one item, over multiple recipes. 

  1. No cool icons (maybe good), doesn't reflect power/time, or any difference between machines
  2. Same as above, but with cool icons, more space to fit in time/energy
  3. One set of ingredients per machine recipe, reflects the current state, but redundant if all recipes have the same costs
  4. Bad example formatting, but the idea is to show the common recipe cost, as well as individual machine differences.
